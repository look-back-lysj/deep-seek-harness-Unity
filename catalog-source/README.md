# 团队内容输入

本目录只存候选模板。没有正式来源、作者授权和发布人时不写生产 URL，也不把本地 fixture 变成正式内容。

- [作者接收与两条发行路线](../docs/contributing/AUTHOR-ONBOARDING.md)
- [目录 v2、组合、来源和撤回](../docs/contributing/CATALOG-CONTENT.md)
- `templates/` 的 null/false 是待确认缺项；校验器应拒绝未填写模板。
- 可执行离线工具在 `scripts/catalog/`，自建样例默认仅写调用者指定的新输出目录。

正式记录按 plugin/release、delivery、presentation、recommendation、release status 分开维护，再用 CatalogAssembly 明确列出各文件。公共 Mojobox 原字节不在这里重定义。
